# 機能改善：全体レビューの6件を修正

2026-09-05。ドキュメント改善のpush後、前回レビューで再現・確認した6件を修正しました。

| 問題 | 修正と確認 |
|---|---|
| 外部ツール終了後にDiffのファイル一覧が古い | ファイル一覧をバックグラウンドで再取得。対象が残れば選択とスクロールを保持し、変更対象から外れた場合は別のファイルへ移動。全変更がなくなれば差分・blameを消去 |
| origin変更後も以前のリポジトリのGitHub情報が残る | キャッシュキーにリモート設定を追加。新しい接続先の取得が失敗しても、旧接続先のCI結果・URL・PR件数を引き継がない |
| Windowsでlazygit/GitUIの.exeを見つけられない | ネイティブの.exe/.comを補完。相対実行パスと相対PATH要素は引き続き拒否し、PATHEXTの任意スクリプト形式を暗黙に実行しない |
| シンボリックリンク等で登録したWorktreeから戻るとHomeが更新されない | 正規化したローカルパスも照合。同じ実体を参照する登録行を更新 |
| 存在しないGIT_DASHBOARD_CONFIG_DIRで初回保存に失敗 | atomic write時に親ディレクトリを作成。ファイル本体は従来どおり一時ファイルからrenameして保存 |
| 一部のWorktree取得に失敗しても対象が分からない | 正常な行と別にエラーパネルを表示。`[` / `]` で失敗対象とエラーを順に確認 |

変更した動作に合わせて、[マニュアル](manual.ja.html)、[キー一覧](reference.ja.md)、
[変更履歴](../CHANGELOG.md#unreleased)を更新し、日英のWorktree画像を再撮影しました。
